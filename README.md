# factorizer
Параллельный факторизатор целых чисел

# Реализация решета

Факторизация выполняется самодостаточным 2LP-SIQS из `siqs_xor.hpp`
(портирован из `tests/siqs_xor.cpp`): один проход по A-полиномам, байтовые
логарифмы в L1/L2-сите, hit-map для больших простых, лес 2LP-циклов и
разреженный гаусс над GF(2) с XOR-историей строк.

* Арифметика — фиксированной ширины (`bignum.hpp`, `UInt<Bits>`,
  алиасы `U128…U4096`); решето работает на 512-битном типе.
* Старые `ubig.hpp`, `u128.hpp`, `siqs.hpp` и `gnfs.hpp` удалены — GNFS
  в программе больше не используется.
* Параллелизм — `std::thread` с привязкой к P-ядрам (`cpu_topology.hpp`).
* Прогресс — сквозной канал `progress_cb` из конвейера и решета в UI:
  полоса и проценты в окне, обновляются по мере сбора соотношений и работы
  Гаусса; значение монотонно (см. `FactorizerBackend::setProgress`).
* Порция полиномов на поток нарастает геометрически, поэтому небольшие числа
  не собирают соотношения «про запас» и не тратят время на Гаусса над
  матрицей в десятки раз больше нужной.

Замеры через `factor_parallel_generic` (8 потоков, `skip_ecm`):

| Число | Время |
| --- | --- |
| 100-битный полупростой | ~1.3 с |
| 205-битный полупростой | ~6.4 с |
| 243-битное составное (3 делителя + остаток) | ~3.2 с |

# Тесты

Исполняемые файлы собираются вручную из корня проекта (Qt не требуется —
нужен только компилятор и `-pthread`):

```powershell
clang++ -std=c++20 -O2 -pthread -I. tests/test_bignum.cpp    -o tests/test_bignum.exe
clang++ -std=c++20 -O2 -pthread -I. tests/test_siqs_xor.cpp  -o tests/test_siqs_xor.exe
clang++ -std=c++20 -O2 -pthread -I. tests/test_pipeline.cpp  -o tests/test_pipeline.exe
```

`tests/factorizer_siqs_etalon.py` — эталонная реализация решета на Python
(для сверки результатов), `tests/siqs_xor.cpp` — исходный прототип,
с которого портирован `siqs_xor.hpp`.
